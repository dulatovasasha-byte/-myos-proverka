# MY OS — проверочный стенд

Стенд проверяет на твоём iPad всё, на чём будет держаться MY OS: связь через VPN, базу данных, хранение файлов, бесплатный ИИ на русском, вход по Face ID, уведомления, фоновую работу по таймеру, публикацию в Telegram через «Поделиться» и русские форматы дат.

Стенд ничего не публикует, не просит пароли и не подключает платные услуги. Карта не нужна.

## Как развернуть (с iPad, без кода)

1. Включи VPN.
2. Нажми кнопку ниже. Войди в Cloudflare и в GitHub, когда попросят.
3. На экране Cloudflare ничего не меняй и нажми **Create and deploy**. Подожди 2–3 минуты.
4. Открой появившийся адрес вида `myos-proverka.….workers.dev` и иди по пунктам на странице.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=__REPO_URL__)

Cloudflare сам создаст базу данных, хранилища, подключит бесплатный ИИ и таймер.

## Что внутри

- `src/index.js` — сервер: проверки, хранение файлов, таймер, уведомления.
- `src/page.js` — страница стенда.
- `src/push.js` — подпись и шифрование уведомлений.
- `wrangler.jsonc` — описание того, что Cloudflare должен создать.
